\section{3. Weekly Report Submission}

Weekly reports should be emailed to \textbf{cfda-members@googlegroups.com}. Please follow the rules below exactly so the automated tracking system can identify your report.

\begin{enumerate}
  \item \textbf{Submission deadline:} Every Monday before midnight.
  \item \textbf{Email subject format:} \texttt{[Weekly Report] YYYYMMDD Name}
  \item \textbf{Date rule:} The date should always correspond to the Monday of that week.
  \item \textbf{Automated confirmation:} After your report is received, you should receive an automatic confirmation email.
  \item \textbf{Automated reminder:} If your report has not been received, the system will send an automatic reminder.
\end{enumerate}

\vspace{0.04in}
Your weekly report should briefly include:
\begin{itemize}
  \item Progress from the past week.
  \item Current issues or blockers.
  \item Plans for the coming week.
\end{itemize}

\section{6. Maintaining This Guide}

This onboarding guide is maintained as a living document. New members are encouraged to help keep it accurate and useful for future lab members.

\textbf{Repository:}
\href{https://github.com/jerewang/CFDA-Lab-Onboarding}{CFDA Lab Onboarding Guide}

After completing your onboarding, if you notice any outdated information, broken links, missing steps, or unclear instructions, please help improve the guide.

\begin{itemize}
  \item For minor updates, such as correcting broken links, contact information, typos, or clarifying existing instructions, you may submit an update through the lab's GitHub repository.

  \item
      If you notice any outdated or unclear information, please open a GitHub Issue or, if you would like to make the update yourself, fork the repository and submit a Pull Request.

  \item Briefly explain what you changed and why in the pull request.

  \item Changes involving lab policies, meeting schedules, reporting requirements, or other lab-wide rules should be confirmed with Prof. Wang before being incorporated.
\end{itemize}

The goal is for each new member to help make the onboarding process a little clearer for the next person.
